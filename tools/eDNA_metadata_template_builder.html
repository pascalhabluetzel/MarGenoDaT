eDNA Metadata Template Builder

Pick the metadata fields that apply to your metabarcoding project and download a CSV template for data entry. Fields come from Darwin Core, the Humboldt extension, the GBIF/OBIS DNA-derived data extension, MIxS and the FAIRe eDNA checklist that eDNAqua-Plan builds on. Sources (definitions are reproduced from the official term lists; the tool works offline):
  • Darwin Core and Humboldt Extension: TDWG term list term_versions.csv, recommended terms (dwc.tdwg.org, CC BY 4.0)
  • MIxS : Genomic Standards Consortium LinkML schema (genomicsstandardsconsortium.github.io/mixs)
  • DNA-derived data extension: GBIF extension definition (rs.gbif.org)
  • FAIRe metadata checklist v, with requirement levels (FAIR-eDNA/FAIRe_checklist; Takahashi et al. 2025, Environmental DNA 7: e70100). FAIRe is the checklist evaluated in eDNAqua-Plan D3.2.
  • OBIS extended MeasurementOrFact extension (rs.gbif.org)
  • OBIS Darwin Core term checklist (manual.obis.org)
Not included: IRI-valued duplicates of Darwin Core terms (dwciri:), deprecated and superseded terms, and the Chronometric Age extension. Catalogue built 20 October 2026.
